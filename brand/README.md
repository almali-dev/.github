# Almali brand

Almali is an **endorsed brand family**: each app leads with its own symbol and name, and Almali signs it
underneath (“by almali”). Every file here is generated by [`scripts/build_brand.py`](scripts/build_brand.py);
edit the script, never the files.

## Rules

- **Naming**: `Almali <Product>`, plus a platform descriptor when it helps: “for Plex · Unraid”, “for Android TV”,
  “for Plex”. “Plex” never comes first in a product name.
- **Master mark**: the lowercase “a” made of three rounded strokes (stroke 11 in a 100-unit grid). The blue hook is
  the family signature and sits **2 units** above the stem. To change the gap, move the hook; never lengthen a stroke.
- **Product symbols**: an ink base plus **one** accent element, drawn on the same grid with the same rounded strokes.
  Avoid chevrons and play triangles, which read as the Plex mark.
- **Lockup**: symbol, product name, then `<descriptor> · by [a] almali`. Keep the wordmark next to the “a”; the
  “a” alone is not yet recognisable.
- **Small sizes**: favicons and 16–32 px icons use the symbol only.

## Files

The master files keep their original names at the top of `brand/`. Each product folder has the same set:

| File | Use |
|---|---|
| `symbol.svg`, `symbol-dark.svg` | The symbol on its own (light / dark backgrounds) |
| `lockup.svg`, `lockup-dark.svg` | README headers, web pages, docs |
| `favicon.svg` | Browser tab icon; switches colours with the browser theme |
| `app-icon.svg` | Rounded dark tile for app launchers, Unraid, PWA |
| `social-preview.svg` | GitHub social preview source |
| `png/` | Raster exports: symbol (512), lockup (1200 wide), app icon (512, 256), `apple-touch-icon.png` (180), `favicon-32.png`, `social-preview.png` (1280×640) |

`llartv/android/res/` holds ready-to-copy Android resources: `mipmap-*/ic_launcher.png`, the adaptive icon
(`mipmap-anydpi-v26/ic_launcher.xml`, `mipmap-*/ic_launcher_foreground.png`, `values/ic_launcher_background.xml`)
and the Android TV banner (`drawable-xhdpi/banner.png`, 320×180).

### Set by hand on GitHub

GitHub has no API for these, so upload them in the web settings:

- Organization avatar: `almali-avatar.png` (organization Settings > Profile).
- Repository social previews: `<product>/png/social-preview.png` (repository Settings > General > Social preview);
  the organization profile uses `png/almali-social-preview.png`.

## Regenerating

```bash
python -m venv .venv && .venv/bin/pip install fonttools resvg-py
curl -L -o SpaceGrotesk.ttf "https://github.com/google/fonts/raw/main/ofl/spacegrotesk/SpaceGrotesk%5Bwght%5D.ttf"
.venv/bin/python brand/scripts/build_brand.py SpaceGrotesk.ttf brand
```
