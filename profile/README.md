# Almali

Self-hosted tools for a better home media setup.

Almali is a small collection of independent, open-source projects for home media
and self-hosting, built and maintained by [@mmarkimark](https://github.com/mmarkimark).
Each project works on its own: install only what you need.

## Projects

| Project | What it does | Status |
|---|---|---|
| [**Almali LlarTV**](https://github.com/almali-dev/almali-llarTV) | A light, fast home screen for Android TV: a large clock, a dock of your favourite apps and a full-screen photo, without recommendation rows or ads. | Available |
| **Almali Smart Cache for Plex · Unraid** | Moves Plex media between slow (HDD) and fast (SSD/NVMe) storage based on viewing patterns, with dry-run, transactional moves and recovery. | Coming soon |
| **Almali Library Curator for Plex** | Shows what nobody watches in a Plex library and why, and removes only what you mark, after a grace period and a final re-check. | Coming soon |

## Principles

- **Safe by default**: read-only or dry-run first; nothing destructive without an explicit decision.
- **Self-hosted**: your data stays on your hardware.
- **Small and focused**: each tool does one job well.
